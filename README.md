# ריטריט כנרת - אפליקציית ניהול אירוע

אפליקציה לניהול אירועים קהילתיים (ריטריטים) - רשימות קניות, הוצאות, תוכנית אמנותית, ציוד והמלצות קנייה, עם ניהול הרשמות והגעות.

## סטאק טכני

- **Expo** (React Native + React Native Web) - קוד אחד ל-iOS, Android ודפדפן
- **Supabase** - Postgres, Auth, Realtime
- **React Navigation** - ניווט בין מסכים
- **Vercel** - אחסון גרסת הוובּ

## סוגי משתמשים

| תפקיד | הרשאות |
|---|---|
| מנהל גדול | משתמש יחיד קבוע (הבעלים), משדרג משתמשים ל"מנהל אירוע" |
| מנהל אירוע | יוצר אירוע, שולח קישור הזמנה, עורך תוכנית אמנותית, ממיין רשימת קניות |
| כוח חלוץ | ברירת מחדל לכל נרשם - מוסיף/מסמן פריטים ברשימות, מתייג אחראים |
| צופה | צפייה בלבד |

## מסכים

1. **התחברות/הרשמה** - כניסה באימייל (magic link) או קוד+סיסמה, שמירת session
2. **אישור הגעה** - תאריך ושעת הגעה משוערת (נדרש בהרשמה ראשונה לאירוע)
3. **דף הבית** - מספר נרשמים, חלוקת לילות (1/2), גרף הגעות לפי שעה
4. **רשימת קניות** - הוספת פריטים, checkbox (מסומן → קו חוצה → יורד לתחתית), תיוג אחראי, מיון לפי קטגוריה + הסרת כפילויות (מנהל אירוע בלבד)
5. **הוצאות** - כל משתמש מוסיף סכום כללי ששילם (ללא קישור לפריט), תצוגת סה"כ וחלוקה לפי לילות-אדם
6. **תוכנית אמנותית** - עריכה ע"י מנהל אירוע בלבד, תיוג אחראי לכל סעיף
7. **המלצות קנייה** - שם מוצר + תיאור + קישור חיצוני (כולל לינקים אפילייט)
8. **רשימת ציוד** - אותו מבנה כמו רשימת קניות (checkbox + קו חוצה)

## מודל נתונים (Supabase / Postgres)

ראה `supabase/schema.sql` לסכימה המלאה. טבלאות עיקריות:

- `profiles` - משתמשים, כולל דגל `is_super_admin`
- `events` - אירועים, כולל `invite_code` לקישור הזמנה
- `event_members` - קישור משתמש↔אירוע, כולל תפקיד, תאריך/שעת הגעה, סכום ששולם
- `shopping_items` - פריטי קנייה, כולל קטגוריה, תיוג אחראי, סטטוס checkbox
- `expenses` - הוצאות כלליות לפי משתמש ואירוע
- `program_items` - סעיפי תוכנית אמנותית
- `equipment_items` - פריטי ציוד
- `recommendations` - מוצרים מומלצים עם קישור חיצוני

## הרשאות (RLS ב-Supabase)

- `is_super_admin` מסומן ידנית בבסיס הנתונים בלבד - לא ניתן להשגה דרך האפליקציה
- הפיכה ל"מנהל אירוע" מתבצעת ע"י מנהל גדול או ע"י תשלום (לוגיקה עתידית)
- כל שאר הפעולות (הוספת פריט, סימון checkbox, הוספת הוצאה) פתוחות לכל חברי האירוע

## הרצה מקומית

```
npm install
npm run web      # להרצה בדפדפן
npm run start    # להרצה עם Expo Go (סריקת QR)
```

צריך קובץ `.env` עם:
```
EXPO_PUBLIC_SUPABASE_URL=...
EXPO_PUBLIC_SUPABASE_ANON_KEY=...
```

## דיפלוי ל-Vercel

- Build Command: `npx expo export --platform web`
- Output Directory: `dist`
- משתני סביבה: להוסיף את מפתחות ה-Supabase תחת Project Settings → Environment Variables
